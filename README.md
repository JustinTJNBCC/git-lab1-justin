# git-lab1-justin

## Question 1: Why does Git show these files as untracked?

Answer: Git shows the files as untracked because, I haven't staged them into the staging area yet.

## Question 2: What information does git diff provide?

Answer: git diff provides me the difference between my last commit and my recent changes.

## Question 3: What is the purpose of git restore?

Answer: git restore reverts any changes made to the file on my local folder it was called with.

## Question 4:

### I. What did git revert do?

Answer: It reverted my local folder to the last commit I made thereby reverting the change I recently just added.

### II. How is git revert different from git restore?

Answer: git revert is different from git restore because git revert tends to revert any changes made that has already been committed while git restore tends to revert a file back to it previous version before making any commits
